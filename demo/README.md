# MacsLink CM – demo stowage plans

Fictitious BAPLIE 3.1 (SMDG31) files for trying MacsLink CM. All data is invented:
vessel MACSLINK PIONEER (fictitious IMO), port call Rotterdam (NLRTM), container numbers with made-up owner codes.

| File | Use in the app |
|---|---|
| `MACSLINK_PIONEER_arrival_NLRTM.edi` | Discharge plan (arrival) |
| `MACSLINK_PIONEER_departure_NLRTM.edi` | Load plan (departure) |

Contents: ~450 containers to discharge, ~660 to load, DG (classes 2.1–9, MP and LQ), reefers, OOG, 45' units and restows.

On Android: tap a file below, then the download button (⤓), and open it from the app's start screen.
